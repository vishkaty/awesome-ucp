# Awesome UCP [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

A curated list of resources for the **Universal Commerce Protocol (UCP)** — the open standard for agentic and headless commerce (AI agents discovering products, running checkouts, and placing orders with merchants).

> Community-maintained. Not affiliated with or endorsed by the official UCP project.

## Official
- [ucp.dev](https://ucp.dev) — protocol home & documentation.
- [Universal-Commerce-Protocol](https://github.com/Universal-Commerce-Protocol) — GitHub org: spec, schemas, samples, conformance suite.
- [Official conformance suite](https://github.com/Universal-Commerce-Protocol/conformance) — the reference test suite (targets spec `2026-01-23`).
